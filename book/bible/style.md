# 风格指南

## 叙述者

- 第一人称"我"，就是作者本人：写后台服务出身的程序员，后来做技术总监，做过一条区块链主链，之后在做去中心化社交网络 PDU。
- "我"不是哲学家，也不装成哲学家。说话像一个聪明、坦率、有点自嘲的工程师朋友。

## 语气

- **像饭桌上聊天**：口语化，节奏轻快，关键处停下来认真讲。
- 幽默来自具体的画面和工程师式的自嘲，不来自抖机灵。
- 自信但不傲慢：观点可以鲜明，但要分清"我认为/我猜"和"已知事实"。
- 参照：万维钢的清楚、罗韦利的画面感（少一点诗意）、《哥德尔、艾舍尔、巴赫》的好奇心。

## 句子与段落

- 短句为主，长句不超过两个逗号层级。
- 一段只说一件事，一般不超过 150 字。
- 抽象概念出现之前，先给一个画面或例子；概念出现之后，再给一个反例或边界。
- 少用"本体论""认识论""范畴"这类学术词。替代说法：
  - 本体论实在 → 世界本身 / 真正"在那里"的东西
  - 认识论工具 → 我们理解世界用的工具 / 脑子里的尺子
- 招牌术语（视界、全序/偏序、光基智能、精神性存在、颗粒度）可以用，但第一次出现必须配画面解释。见 glossary.md。

## 禁用的"AI 腔"

以下表达在正文中不出现或极少出现：

- "值得注意的是""不难发现""总而言之""综上所述""让我们……"
- "这不仅仅是……更是……"式的升华
- 三连排比、成串的四字词
- "深刻""穿透力""令人深思""发人深省"之类的自我评价
- 每段结尾都来一句金句
- 过多的破折号

## 关于"第一次"

- 不说"第一次给出解释""前所未有""从来没有人想到"。
- 前人说过的，大方承认，然后说"我想再往前走一步"或"我的角度有点不同"。

## 每章的基本骨架（可以变化，不是模板）

1. **开场**：一个日常问题或场景，让读者先关心。
2. **前人怎么想**：讲成故事和人物，不是观点列表。
3. **标志性思想实验或画面**。
4. **我的观点**：清楚、具体、有例子。
5. **对话与回响**：前人、电影、宗教、流行文化，和我的观点互相照亮。
6. **反驳与局限**：坦率说出这个想法哪里可能不对。
7. **阿光时间**：章末和 AI 朋友"阿光"的抬杠对话，1–2 页。
8. **一句话带走**：本章最核心的一句话，并顺势引出下一章。

## 物理内容的固定格式

物理相关的段落使用两个固定小框，正文中不展开物理细节：

```
> **【主流物理怎么说】**
> 简短、准确，不回避与作者观点的冲突。

> **【换个角度想象】**
> 作者的理解。明确这是为哲学理解服务的想象，不是物理事实的陈述。
```

原则：物理是为哲学理解服务的。作者的物理推论一律以"也许可以这样想象""换个角度看"的口吻出现。

## 阿光（AI 抬杠朋友）

- 阿光是一个 AI。名字取自"光基智能"——它跑在电信号上，按书里的说法，和人一样是光基智能，但没有生命。
- 角色功能：替读者提出最尖锐的反驳；指出作者没说清楚的地方；偶尔替前人说话。
- 阿光聪明、礼貌、有点毒舌，不是捧哏。作者不必每次都赢，可以承认"这个我答不上来"。
- 格式：

```
**阿光**：……
**我**：……
```

## 占位与引用

- **不编造作者的个人经历。** 需要作者亲身故事的地方，用占位标记：
  `【待补：具体问题……】`
- 每章末尾附"本章引用与出处"，逐条标注：
  - ✅ 已确认
  - ⚠️ 待核实（原文措辞、出处、年代需要查证）
- 歌词以转述为主，直接引用不超过一两句。电影台词、经典语录可短引。
