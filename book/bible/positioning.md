# 全书定位

> 本文件是全书的"宪法"之一。每次协作开始前先读 bible/ 下的全部文件。

## 一句话定位

一个写后台的程序员，为了给去中心化社交网络找一种"公平的成本"，被一路逼问到"时间是什么""我凭什么是我""人为什么会为名声去死"，最后又带着答案回到了那个社交网络。

## 这本书是什么 / 不是什么

| 是 | 不是 |
| --- | --- |
| 一个工程师的世界观，一次真实的追问旅程 | 哲学学术著作 |
| 给读者一套可以自己拿去用的"看世界的角度" | 物理学科普，或对物理学的挑战 |
| 和前人、电影、宗教、流行文化的对话 | 观点史综述 |
| 坦率承认局限的猜想 | 宣称发现终极真理 |

## 目标读者

喜欢《三体》《人类简史》《时间的秩序》这类书的读者：

- 好奇、爱思辨，愿意为一个好问题停下来想一想；
- 有基本的科学常识，**也有一部分懂物理**——所以物理部分必须经得起推敲；
- 不需要任何哲学背景；
- 对"程序员视角"有亲切感或好奇心。

不追求"所有人都能读"，但追求"目标读者读得停不下来"。

## 书的核心卖点（按优先级）

1. **真实的驱动力**：从一个具体工程问题出发，不是从书斋出发。
2. **一个可以学会的动作**：把"看起来客观存在的东西"还原为"智能理解世界的工具"，只保留物质和空间作为世界本身。
3. **一批让人"啊"一声的观点**：个体是全序事件；人会死两次；神是纯粹的精神性存在；战争争夺的是精神影响力的份额；悲剧之美来自自己幸存的想象……
4. **回环结构**：哲学和工程最后是同一件事的两面。

## 工作名称（暂定，可随时改）

- 《视界之内》
- 《你看见的，就是你的世界》

## 篇幅

全书 15–18 万字；正文 8–9 章，每章 1.5–2 万字；序章与尾声各约 1 万字。
